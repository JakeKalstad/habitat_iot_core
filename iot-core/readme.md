# IOT Core

Firmware for devices

## Deps

Requires espup and rust, to use cargo run you should have an esp plugged into usb to run on

## Run 

cargo run --features bare,motion_sensor

### features to run 
bare 
motion_sensor 
temp_humidity 
temp_pressure
water_sensor 
reed_switch 
air_quality
display
servo 
motor
reset_volatile 
host
